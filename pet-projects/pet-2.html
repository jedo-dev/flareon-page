Tower Def

Мобильная браузерная игра в жанре tower defense, вдохновленная Warcraft 3: дуэль против компьютерного противника. Строишь лабиринты из башен, защищаешь свою полосу — или инвестируешь золото в отправку врагов противнику по классической экономике WC3.

Код на GitHub

Особенности

  • Режим дуэли против ИИ: защита своей полосы и отправка волн противнику
  • Экономика в духе Warcraft 3 — баланс между башнями и инвестициями в атаку
  • Типизированный мост React ↔ Phaser для связи UI и игрового движка
  • Бизнес-логика покрыта модульными тестами (Vitest)
  • Подробная проектная документация: геймдизайн-док, roadmap, инженерные правила

Технологии
